An Android voice assistant and a floating menu with different functions. In active development.

CURRENTLY VERY ROUGH AND BUGGY, NOT FOR EVERYDAY USE (and basically almost any use). THIS APP IS NOT DONE! UI is being reworked now, and it's not ready to be shown. Voice assistant has basic functionality, but its settings don't work stable. Floating menu has bugs with UI and some of its functions don't work on non-rooted devices.
This repo is mainly for the source code, don't waste your time for it, unless you want to look at the code.
